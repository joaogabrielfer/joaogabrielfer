## Selected projects

### [Fobos](https://github.com/joaogabrielfer/fobos)

A typed interpreted programming language implemented in Rust. It includes a lexer, parser, evaluator, type checker, scoped environments, source-aware diagnostics, a CLI and REPL, and fixture-based regression tests.

### [Island Shell](https://github.com/joaogabrielfer/island-shell)

A modular desktop shell for Hyprland built with QML and Quickshell. It provides an interactive bar, adaptive application launcher, dashboard, persistent command modes, typed configuration, IPC, live reload, and an extension system.

### [hypr-overview](https://github.com/joaogabrielfer/hypr-overview)

A C++23 plugin for Hyprland's scrolling layout that renders animated, live workspace previews without changing the underlying window arrangement. It supports keyboard and mouse navigation, configurable rendering, a Lua API, and Hyprland plugin-manager packaging.

### [lexrule](https://github.com/joaogabrielfer/lexrule)

A small regex-based lexer library for Rust with longest-match rule selection, source spans, skipped input, UTF-8-aware positions, and descriptive construction and tokenization errors.
